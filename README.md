# نت‌نگار · Notnegar

**تحلیل و نت‌نگاری خودکار موسیقی ایرانی**
*Persian music analysis and transcription*

نت‌نگار یک فایل صوتی می‌گیرد و دستگاه، نت پایه، کوک و تمپوی آن را تشخیص می‌دهد، نت ملودی را با علامت‌های کرن و سری می‌نویسد و یک PDF آماده‌ی چاپ برای نوازنده می‌سازد.

## وضعیت فعلی: نمونه‌ی اولیه (فاز ۰)

کل نمونه‌ی اولیه یک فایل است: [`index.html`](index.html). بدون سرور و بدون نصب در مرورگر اجرا می‌شود و فایل صوتی از رایانه‌ی کاربر خارج نمی‌شود.

### اجرا

فایل `index.html` را در مرورگر باز کنید، یا با GitHub Pages منتشرش کنید:
Settings → Pages → Branch: `main` / root.

### امکانات

- آپلود MP3، WAV، OGG یا M4A (دو دقیقه‌ی اول تحلیل می‌شود)
- تشخیص دستگاه از میان شور، ماهور، همایون، بیات اصفهان، سه‌گاه، چهارگاه و نوا، با درصد اطمینان و گزینه‌ی دوم
- تشخیص نت پایه و انحراف کوک ضبط از لا ۴۴۰ هرتز
- تخمین تمپو و وزن، یا تشخیص اجرای آزاد و بی‌وزن
- جدول کوک برای سنتور، تار و سه‌تار، کمانچه، نی و سازهای غربی (فرکانس و اختلاف با پیانو به سنت)
- نت‌نویسی ملودی در کلید سل با سرکلید دستگاه، کرن، سری و نام فارسی زیر نت‌ها
- امکان تعیین دستی دستگاه و نت پایه
- پخش نت‌های تشخیص‌داده‌شده برای مقایسه با اصل
- ساخت PDF چندصفحه‌ای A4 (خلاصه‌ی تحلیل، جدول کوک، نمودارها، نت)

### روش کار

1. **ردیابی ارتفاع صدا:** الگوریتم YIN روی صدای تک‌کاناله‌شده با نرخ حدود ۱۱ کیلوهرتز
2. **کوک مرجع:** میانگین دایره‌ای انحراف فرکانس‌ها روی شبکه‌ی ۵۰ سنتی (ربع‌پرده)
3. **کوانتیزه کردن:** هر فریم به یکی از ۲۴ ربع‌پرده‌ی اکتاو نگاشت می‌شود
4. **تشخیص دستگاه:** مقایسه‌ی هیستوگرام ربع‌پرده‌ها با الگوی درجه‌های هر دستگاه، برای هر نت پایه‌ی ممکن؛ نت ایست جمله‌ها وزن بیشتری دارد
5. **ریتم:** خودهمبستگی شروع نت‌ها برای تمپو و وزن، سپس کوانتیزه کردن دیرندها

### محدودیت‌های این نسخه

- سازها از هم جدا نمی‌شوند؛ ملودی غالب کل صدا نت‌نویسی می‌شود، پس دقت روی آهنگ‌های شلوغ چندسازی پایین‌تر است
- آوازهای هم‌خانواده‌ی شور (ابوعطا، دشتی، بیات ترک، افشاری) و راست‌پنجگاه از دستگاه مادرشان جدا نمی‌شوند
- تقسیم ریتمی ساده است و نت‌های عبورکننده از خط میزان به هم وصل (tie) نمی‌شوند
- ارسال PDF به ایمیل نیاز به نسخه‌ی سروری دارد

## English summary

Notnegar takes an audio file and detects its Persian *dastgah*, tonic, reference tuning and tempo, transcribes the melody with *koron* and *sori* quarter-tone accidentals, and produces a printable PDF for musicians. This repository holds the phase-0 prototype: a single self-contained `index.html` that runs entirely in the browser (YIN pitch tracking, 24-tone-per-octave histogram matching against dastgah templates, onset autocorrelation for tempo, a canvas staff renderer and a dependency-free PDF writer). Phase 1 moves analysis to a server with source separation (Demucs), CREPE pitch tracking and LilyPond engraving.
